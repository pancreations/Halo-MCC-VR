===========================================================

Observed Stage 2B failure
-------------------------
The Stage 2B runtime log proves that Y+B successfully requests and completes
Halo 2's head-locked 2D pause transition, but Halo 2's synchronous presentation
policy immediately classifies the current frame as a frame-local Drop. That
policy intentionally refuses to sample an unproven H2 backbuffer, so after the
comfort fade completes OpenXR reaches layers=0 and the headset is black.

The second Y+B switches back to stereo 3D and the H2 synchronous compositor
resumes as soon as a projection-ready exact-current-serial pair exists.

C-H2-72 source policy
---------------------
Once BOTH of these are true:
  1. the current title/frame is Halo 2, and
  2. g_pausePresentation says the displayed presentation is already head-locked
     pause mode,
Halo 2 deliberately selects the shared stock-screen presentation instead of
applying the synchronous eye-pair Drop decision.

This is intentionally NOT keyed from the pending pause target. The existing
opaque comfort fade therefore still covers the transition edge, and failed H2
stereo frames outside a displayed pause retain the strict no-unproven-backbuffer
Drop policy.

Why the stock screen is valid here
----------------------------------
During an intentional pause the desktop/backbuffer is the desired source: MCC
renders the native Halo 2 pause menu there. The shared head-locked screen path
already knows how to copy that source into the OpenXR screen quad.

The direct patch:
- reuses unused padding in the existing Stage 2A `.h2aa` section
- changes only the H2 synchronous-presentation decision path

- forces SharedDefault only for that intersection
- replays the displaced instruction and returns to stock code
- does not add a new section/page or alter H3/ODST/Reach/H4 code/data

Testing focus
-------------
1. Halo 2 Anniversary: enter gameplay, press Y+B.
   Expected: native pause menu is visible on the head-locked 2D screen.
2. Press Y+B again.
   Expected: comfort fade and stereo gameplay return.
3. Repeat several times.
4. Repeat in Halo 2 Classic graphics.
5. Briefly verify another supported title still enters VR.

Important resume caveat
-----------------------
Halo 2 still does not have an authoritative H2-native pause-state binding in
this branch. For THIS test, use Y+B to enter and Y+B to leave the pause screen.
If selecting Resume / pressing B inside the native pause menu resumes the game
but leaves the headset in head-locked 2D, report that separately. That would be
a distinct H2EK-first native pause-state synchronization task, not a failure of
the Stage 2C screen-delivery fix.
